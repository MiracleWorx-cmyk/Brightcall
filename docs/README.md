# Brightcall

**Brightcall** is the game (one word). **Aethora** is the world.

A fast hex brawler played inside **The Bright**. Characters mutate through a shared **Splintered** deck. Kills and objectives score. First to 15 victory points.

Every page is English. Locked nouns: [terminology](terminology.md). Visual lock: [art direction](gdd/art-direction.md).

## Leading lock

- Two energies: **Bright energy** (causes Seams; Core emission) and **Chroma** / Bright-Tears (ooze at Seam edges; Magenta, Cyan, Searing Gold only).
- **Seams:** fleeting Bright-energy satin curtains. Erupt, envelop, rewrite while active, always weep, then end and restore the original. Not hex borders. No permanent scars.
- **Splinters:** Bright-powered Null-Flint; primary in-match Seam cast. Players can cast Seams. Event-deck Seam casting not locked yet.
- Kho'Lan and Adumbra cleanse / pinch Seams (pinch name open). Lumari may interact with weeping Chroma. Touch is always dangerous in lore.
- **Eclipse** = Bright rim. **Umbras** = entry and Stitching return.
- Applications: **Bloom**, **Splintered**, **Brightforged**, **Chroma-fuel**.
- Factions: Kho'Lan, Lumari, Kardia, Refract Labs, the Aureate, Adumbra.
- Aesthetic: **Bright-punk Fantasy** — Bone/Ash/Greige, Bruised Darkness, toxic neon Chroma.
- Eras: First Bright → Traveling Light → Resting Light. **Stitching**. No Weld.

If a new request conflicts with this lock, ask before editing.
