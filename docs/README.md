# Brightcall

**Brightcall** is the game (one word). **Oros** is the world.

A fast hex brawler played inside **The Bright** — one vast cube of light whose monolithic living terrain tries to consume Harvesters. Appetite Seams wrap them mid-match as **Enhancements**. A shared **Splintered** deck is Splinter-Crush synthetic Seam weaponry. Kills and objectives score. First to 15 victory points.

Every page is English. Read the world as one lorebook. The nouns live in [terminology](terminology.md). The look lives in [art direction](gdd/art-direction.md).
